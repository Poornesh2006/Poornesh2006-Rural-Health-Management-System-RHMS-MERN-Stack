# Screenshot Guide

Capture the following screens using demo data and stable UI states.

1. Login: seeded demo admin account visible, clean background, no error state
2. Admin dashboard: summary cards loaded, queue and notification widgets visible
3. Reception dashboard: patient intake and appointment shortcuts visible
4. Patient registration: partially filled fictional patient form
5. Patient list: search results with varied villages and risk badges
6. Patient profile: timeline with visit, prescription, lab, and vaccination entries
7. Appointment booking: doctor selected and slot list visible
8. Token queue: waiting and called sections visible
9. Doctor consultation: active consultation form with vitals and notes
10. Prescription: pending and dispensed examples
11. Pharmacy dashboard: low-stock and batch selection state
12. Dispensing screen: selected batch and quantity fields visible
13. Lab dashboard: pending requests and verified report example
14. Lab report: verified result with safe, non-graphic values
15. Vaccination dashboard: due list and recorded dose example
16. Vaccination certificate: printable certificate screen
17. Analytics dashboard: executive metrics and village insights
18. Village health dashboard: filtered regional view
19. Reports: preview plus export buttons
20. Tamil interface: switch language and capture translated navigation
21. Offline mode: visible offline badge and pending sync count
22. Notification center: unread and read examples
23. Referral workflow: sent referral with consent reference
24. AI review: disclaimer, redacted summary, accept/reject actions
25. Mobile responsive view: narrow viewport dashboard or registration screen

Recommended capture tips:

- Use synthetic data only
- Prefer clean states with one main message per screenshot
- Keep browser zoom at 100 percent unless highlighting accessibility
- Capture both light and dark themes only if time permits
