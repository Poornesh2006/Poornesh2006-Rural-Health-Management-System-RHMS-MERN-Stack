# Maintenance Guide

## Daily

- Check health endpoints
- Review failed jobs or visible errors
- Confirm backup status if backups are enabled

## Weekly

- Review audit and notification issues
- Review stock expiry and low-stock alerts
- Review sync failures and offline queue issues

## Monthly

- Review dependencies for updates
- Review database performance and indexes
- Review backup and restore process
- Review user access and stale accounts

## Release Maintenance

- Branch carefully after change freeze
- Verify builds after each bug fix
- Update changelog and release notes
- Confirm rollback steps before deployment
