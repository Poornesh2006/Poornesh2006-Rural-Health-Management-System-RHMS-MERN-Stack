# Deployment

- Purpose: Prepare the project for hosted demonstration and future expansion
- Users: Admin, developer, evaluator
- Workflow: install dependencies, configure env, build frontend, start backend
- Data model: not module-specific
- APIs: health endpoints support deployment smoke checks
- Main pages: presentation and dashboard
- Permissions: environment and host-controlled
- Error cases: missing env, MongoDB unavailable
- Security controls: secret separation and production config expectations
- Tests: frontend build and backend import verification
- Known limitations: Docker and hosted release verification not fully completed
