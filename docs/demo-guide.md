# Demo Guide

## Demo Mode

- Synthetic data only
- Academic and evaluation use only
- Do not use real patient information

## Suggested Demo Accounts

These are development/demo placeholders and should not be treated as production credentials.

- Super Admin: `admin@rphc.gov` / `Admin@123`
- Facility Admin: `facilityadmin@rphc.gov` / `Admin@123`
- Doctor: `doctor@rphc.gov` / `Admin@123`
- Receptionist: `reception@rphc.gov` / `Admin@123`
- Pharmacist: `pharmacy@rphc.gov` / `Admin@123`
- Lab Technician: `lab@rphc.gov` / `Admin@123`
- Health Worker: `healthworker@rphc.gov` / `Admin@123`
- Evaluator: `evaluator@rphc.gov` / `Admin@123`

Note:

- Some roles may require additional seeding support if not yet added to the current database.
- Use the admin account for a safe fallback during evaluation.
